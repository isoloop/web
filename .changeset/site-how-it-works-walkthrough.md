`/how-it-works/` is a walkthrough of the runtime instead of a row of diagrams: the host and its isolates, workers and pools, topics and the bus, rendering from a worker, the supervisor, restarts and catch-up, a bus crash, and grants. Each step has short type-checked code and, where it helps, the diagram drawn from the library's code. The landing page's link to it now reads "How it works, part by part".
