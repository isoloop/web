`/how-it-works/` is a walkthrough of the runtime instead of a row of diagrams, one step at a time behind a row of step tabs: the overview, the host and its isolates, workers and pools, topics and the bus, rendering from a worker, the supervisor, restarts and catch-up, persistence and bus crashes, and grants. Each step has short type-checked code and, where it helps, the diagram drawn from the library's code, at the page's full width as the drawing alone, sized so all of it shows (Open full size has the viewer's presentation mode and controls), and described in words: its parts, then its arrows in order. The diagrams' own titles now show in their frames' names and links. The landing page's link to it now reads "How it works, part by part". Code inside prose is set as a chip on every page, so it reads apart from the words around it.
