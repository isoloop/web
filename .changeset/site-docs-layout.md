The docs are reachable: "Docs" is in the header, after Examples (ADR 0006, amending ADR 0005), and opens `/docs/`, which lists every section and guide with its one-line description. Each guide's page has the docs layout: the section sidebar with the current page marked and an Experimental pill on the balancer and the devtools panel, the lead, a meta line (Source on GitHub, the Markdown copy, the `@isoloop/*` version it describes), "On this page" on the right, code blocks with a Copy button, and Previous and Next. Below 1100px the contents fold under the meta line, and below 760px the sidebar folds into a "Docs" block at the top. The footer links `/llms.txt`, and the docs pages are in the sitemap.
