The docs have a search box at the top of their sidebar (and of `/docs/` on a phone): it matches page titles, headings and text from a small index built with the site (`/docs/search.json`), and `/` focuses it. Every docs page links its own Markdown copy ("View as Markdown"), and `/docs/` points agents at `llms.txt` and `llms-full.txt`.
